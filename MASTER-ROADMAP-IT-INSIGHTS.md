## 🛠️ STANDAR TEKNIS (tidak boleh berubah)

### SmartCrawl Pro — Checklist Artikel Blog
- [ ] Focus keyphrase ada di paragraf pertama (kalimat 1-3)
- [ ] Focus keyphrase ada di H1
- [ ] Focus keyphrase ada di minimal 1 H2
- [ ] Keyword density 1-2%
- [ ] Alt text gambar mengandung focus keyphrase
- [ ] Title tag 50-60 karakter
- [ ] Meta description 120-160 karakter
- [ ] Minimal 1 internal link ke artikel lain
- [ ] Minimal 1 external link ke sumber terpercaya

### Struktur Artikel Blog (Baku)
```
H1 (mengandung keyphrase)
→ Paragraf pertama (keyphrase dalam 100 kata pertama)
→ H2 "Apa itu [X]"
→ Konten utama (H2/H3)
→ Infografis dengan alt text keyphrase
→ Kesimpulan
→ CTA + internal link ke artikel sebelumnya
```

### Reels — Format yang Disepakati
- Tidak langsung ke kamera (Seandy tidak nyaman)
- Format: screen recording + AI voiceover (CapCut Text-to-Speech)
- Alternatif: text-on-screen / caption style tanpa wajah

### Engagement Strategy (update post Minggu 1)
- Self-comment dalam 60 menit setelah posting (2-3 komentar bermakna)
- CTA spesifik yang mendorong reply (bukan "like dan share")
- Carousel dirancang untuk save/share, bukan sekadar read
- Posting LinkedIn: 07.30 WIB (bukan tepat 07.00)
