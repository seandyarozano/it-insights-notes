# Routing Table: Peta Perjalanan Data di Jaringan Komputer > Bagian dari seri IT Insights Notes — penjelasan teknis dalam bahasa sederhana ## Apa itu Routing Table? Routing table adalah daftar "petunjuk arah" yang dimiliki setiap perangkat jaringan (router, komputer, server). Isinya: ke mana paket data harus dikirim berdasarkan alamat tujuannya. Analoginya seperti buku tamu + peta di sebuah hajatan. Saat kamu datang dan tidak kenal siapapun, kamu butuh seseorang yang tahu: "meja makan ada di sana, kamar mandi di sana, tuan rumah ada di sana." Tanpa routing table → komputer bingung → data nyasar → tidak sampai tujuan. ## Komponen Utama Routing Table | Kolom | Fungsi | |-------|--------| | Destination | Alamat IP tujuan paket data | | Subnet Mask | Menentukan rentang jaringan | | Gateway | Pintu keluar menuju jaringan lain | | Interface | Kartu jaringan yang digunakan | | Metric | "Biaya" jalur — semakin kecil semakin diprioritaskan | ## Jenis Routing Static Routing - Dikonfigurasi manual oleh admin jaringan - Tidak berubah kecuali diubah secara manual - Cocok untuk jaringan kecil dan sederhana Dynamic Routing - Router saling berbagi informasi jalur secara otomatis - Bisa menyesuaikan diri jika ada jalur yang mati - Protokol umum: OSPF, BGP, RIP, EIGRP ## Analogi Kehidupan Nyata | Konsep IT | Analogi | |-----------|---------| | Routing table | Peta + buku tamu hajatan | | Gateway | Pintu masuk gedung | | Static route | Rute yang sudah dihapal | | Dynamic route | GPS yang update otomatis | | Metric | Jarak tempuh — pilih yang paling dekat | ## Perintah Dasar (untuk referensi) ```bash # Lihat routing table di Linux ip route show # Lihat routing table di Windows route print # Tambah static route di Linux ip route add 192.168.2.0/24 via 192.168.1.1 ``` ## Kaitannya dengan Konten LinkedIn Post LinkedIn: [Pelajaran Networking dari Kehidupan Sehari-hari] Analogi yang dipakai: datang ke hajatan tanpa kenal siapapun = komputer tanpa routing table yang benar. --- *IT Insights Notes · github.com/username-kamu/it-insights-notes*
