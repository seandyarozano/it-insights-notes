# DNS untuk Pemula: Buku Telepon Internet > Bagian dari seri IT Insights Notes — penjelasan teknis dalam bahasa sederhana ## Apa itu DNS? DNS (Domain Name System) adalah sistem yang menerjemahkan nama domain (seperti google.com) menjadi alamat IP (seperti 142.250.185.78) yang dimengerti oleh komputer. Analoginya: buku telepon internet. Saat kamu ketik "google.com", komputer tidak tahu itu siapa. DNS yang mencari: "oh, google.com itu alamatnya 142.250.185.78, sampaikan ke sana." Tanpa DNS → kamu harus hafal alamat IP setiap website yang ingin dikunjungi. ## Cara Kerja DNS (Step by Step) ``` Kamu ketik: google.com ↓ 1. Browser cek cache lokal — sudah pernah visit? ↓ (tidak ada) 2. Tanya Recursive Resolver (biasanya dari ISP) ↓ 3. Resolver tanya Root Nameserver — siapa yang pegang .com? ↓ 4. Root arahkan ke TLD Nameserver (.com) ↓ 5. TLD arahkan ke Authoritative Nameserver Google ↓ 6. Dapat IP address: 142.250.185.78 ↓ Browser buka google.com menggunakan IP tersebut ``` ## Komponen Utama DNS | Komponen | Fungsi | |----------|--------| | DNS Resolver | Perantara antara kamu dan DNS server | | Root Nameserver | Titik awal pencarian DNS — ada 13 di dunia | | TLD Nameserver | Mengelola domain seperti .com, .id, .net | | Authoritative NS | Penyimpan data DNS final sebuah domain | | DNS Cache | Hasil pencarian yang disimpan sementara | ## DNS Record yang Paling Penting | Record | Fungsi | |--------|--------| | A | Domain → IPv4 address | | AAAA | Domain → IPv6 address | | CNAME | Alias — domain ke domain lain | | MX | Mengarahkan email ke mail server | | TXT | Verifikasi dan informasi tambahan | | NS | Nameserver yang bertanggung jawab atas domain | ## Studi Kasus: Cloudflare Down 18 November 2025 Saat Cloudflare mengalami gangguan, DNS server mereka ikut bermasalah. Akibatnya: - ChatGPT, X, Spotify tidak bisa diakses - Browser mendapat pesan error bukan karena servernya mati - Tapi karena DNS tidak bisa "menerjemahkan" nama domain ke IP - Seperti buku telepon yang tiba-tiba hilang **Pelajaran:** DNS adalah infrastruktur paling kritis tapi paling sering diabaikan. Satu gangguan DNS bisa membuat website "hilang" dari internet meski servernya masih berjalan normal. ## Tools untuk Cek DNS ```bash # Cek DNS record sebuah domain nslookup google.com # Lebih detail dig google.com # Cek dari DNS server tertentu dig @8.8.8.8 google.com # Cek waktu TTL (Time To Live) dig google.com +ttl ``` ## Kaitannya dengan Konten - Post LinkedIn: Cloudflare Down 5,5 Jam (Kamis Minggu 1) - Artikel Medium: Penyebab Cloudflare Down 18 November 2025 - Analogi: DNS = buku telepon internet --- *IT Insights Notes · github.com/username-kamu/it-insights-notes*
